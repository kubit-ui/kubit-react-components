# Changesets

This directory contains changesets for the kubit-react-components monorepo.

## What are changesets?

Changesets are a way to manage versioning and changelogs with a focus on monorepos. They allow contributors to declare how their changes should be released.

## How to use

This monorepo uses **automatic changeset generation** based on your branch name and commit scope. You don't need to manually create changesets - they're generated automatically when your PR is merged!

For more information, see the [CONTRIBUTING.md](../CONTRIBUTING.md) file.
