# @kubit-ui-web/react-components

Kubit React Components is a customizable, accessible library of React web components, designed to enhance your application's user experience.

## Installation

```bash
npm install @kubit-ui-web/react-components @kubit-ui-web/design-system
# or
pnpm add @kubit-ui-web/react-components @kubit-ui-web/design-system
# or
yarn add @kubit-ui-web/react-components @kubit-ui-web/design-system
```

## Usage

```tsx
import { Button } from '@kubit-ui-web/react-components';
import { KubitProvider } from '@kubit-ui-web/design-system';

function App() {
  return (
    <KubitProvider>
      <Button>Click me</Button>
    </KubitProvider>
  );
}
```

## Features

- 🎨 Highly customizable components
- ♿️ Accessibility-first approach (WCAG 2.1 AA)
- 📦 Tree-shakeable
- 🔧 TypeScript support
- 🎭 Compound components pattern
- 🧪 Fully tested
