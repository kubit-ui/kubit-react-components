# @kubit-ui-web/storybook

Storybook documentation and showcase for Kubit components.

## Development

```bash
pnpm storybook
```

This will start Storybook on http://localhost:6006

## Build

```bash
pnpm build
```

This will build the static Storybook site to the `dist` directory.

## Deployment

This package is automatically deployed to Vercel on every push to main.
